# Palette Studio 更新配布

Palette Studio（パレットスタジオ）の自動アップデート用の配布専用リポジトリです。ソースコードや署名の鍵は置いていません。

- `latest.json` … アプリが最初に読む、最新版の情報
- `updates/` … 署名付きの更新ファイル（最新の1つだけ）

更新ファイルは電子署名（ed25519）が付いており、アプリは正式なもの以外を使いません。
アプリのメニュー「ヘルプ → 更新を確認…」でも確認できます。

## 入れ方（別のパソコン）

`setup/install-palette-studio.bat` をダウンロードして実行すると、インストーラーを自動で取得して起動します（約116MB。デスクトップのショートカットと画像の関連付けが入ります）。
